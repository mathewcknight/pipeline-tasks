Setup Instructions

  1. Open the GMS Reporting folder called Pipeline Sheet and save a copy of the Megadash Pipeline report. Update the filters to show your own name instead of MK.
  2. When you want to refresh your data, download a fresh report as Details Only, xlsx format and save it to your dashboard folder, replacing the existing pipeline_data.xlsx.
  3. Make sure all required files are in the same folder: megadash.html, megadash.css, pipeline_data.xlsx, panel_dates.xlsx, task_definitions.xlsx, xlsx.full.min.js.
  4. Click Select Dashboard Folder to load your data.
