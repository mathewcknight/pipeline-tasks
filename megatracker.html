Project Megatracker
How to use: Add a project tab for each active investment you're managing. Fill in the project name, approval authority, and any known stage dates — the tracker will calculate task due dates automatically. Tick tasks off as you complete them. Use the Next 2 Weeks panel to focus on what's coming up, and expand stage sections in All Tasks to see the full checklist.

This dashboard is a best practice minimum. There are many variations to this required to take any individual project through the ARENA process and you should use this as a checklist to cover all mandatory steps in time.
